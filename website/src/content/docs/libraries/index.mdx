SharpCampus is a reference server that weaves MagicOnion and the Cysharp ecosystem libraries into a working whole. This section explains one library per page, in the order of "what it is → why it's here → where and how this project uses it → code links." When you want to see where a piece sits in the bigger structure, the [architecture section](../architecture/) is the map.

:::note[The two pillars not here: UniTask and YetAnotherHttpHandler]
Two Cysharp libraries that pair with a Unity client make no appearance in this project. [UniTask](https://github.com/Cysharp/UniTask) is a zero-allocation async/await implementation fitted to Unity's player loop, and [YetAnotherHttpHandler](https://github.com/Cysharp/YetAnotherHttpHandler) is the HTTP handler that lets Unity speak gRPC (HTTP/2). This project's client is a .NET console app, where standard async/await and the default HTTP stack are enough — so neither had a place. The day a Unity client is attached, these are the first two packages to arrive.
:::
