SharpCampus は、MagicOnion と Cysharp エコシステムのライブラリを実戦の形で編み込んだリファレンスサーバーです。このセクションではライブラリ 1 つにつき 1 ページ、「何か → なぜ使うのか → このプロジェクトのどこでどう使われているか → コードリンク」の順で解説します。全体構造の中での位置が気になったら、[アーキテクチャセクション](../architecture/)が地図になります。

:::note[ここにない 2 本の柱: UniTask と YetAnotherHttpHandler]
Cysharp エコシステムで Unity クライアントと対になる 2 つのライブラリは、このプロジェクトには登場しません。[UniTask](https://github.com/Cysharp/UniTask) は Unity のプレイヤーループに合わせたゼロアロケーション async/await 実装で、[YetAnotherHttpHandler](https://github.com/Cysharp/YetAnotherHttpHandler) は Unity で gRPC(HTTP/2)を話せるようにする HTTP ハンドラーです。このプロジェクトのクライアントは .NET コンソールアプリで、標準の async/await と既定の HTTP スタックで足りるため、どちらにも出番がありませんでした。Unity クライアントをつなぐ日が来たら、真っ先に追加される 2 パッケージです。
:::
