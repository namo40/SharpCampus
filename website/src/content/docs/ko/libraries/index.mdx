SharpCampus는 MagicOnion과 Cysharp 생태계 라이브러리를 실전 형태로 엮은 레퍼런스 서버입니다. 이 섹션은 라이브러리 하나마다 한 페이지씩, "무엇인가 → 왜 쓰나 → 이 프로젝트 어디에 어떻게 쓰였나 → 코드 링크" 순서로 해설합니다. 전체 구조 안에서의 위치가 궁금해지면 [아키텍처 섹션](../architecture/)이 지도가 되어 줍니다.

:::note[여기 없는 두 기둥: UniTask와 YetAnotherHttpHandler]
Cysharp 생태계에서 Unity 클라이언트와 짝을 이루는 두 라이브러리는 이 프로젝트에 등장하지 않습니다. [UniTask](https://github.com/Cysharp/UniTask)는 Unity 플레이어 루프에 맞춘 제로 할당 async/await 구현이고, [YetAnotherHttpHandler](https://github.com/Cysharp/YetAnotherHttpHandler)는 Unity에서 gRPC(HTTP/2)를 쓸 수 있게 하는 HTTP 핸들러입니다. 이 프로젝트의 클라이언트는 .NET 콘솔 앱이라 표준 async/await와 기본 HTTP 스택으로 충분해서 둘 다 쓸 자리가 없었습니다. Unity 클라이언트를 붙이는 날이 오면 가장 먼저 추가될 두 패키지입니다.
:::
